# SkylineHero artwork

`hero.svg` is vendored **verbatim** from the owner's GitHub profile
README (owner decision in `docs/design/refresh-plan.md`). Do not edit it here;
re-copy it when the profile changes.

- Source: <https://github.com/THEtheChad/THEtheChad/blob/main/assets/hero.svg>
  (raw: <https://raw.githubusercontent.com/THEtheChad/THEtheChad/main/assets/hero.svg>),
  generated by that repo's `tools/build_assets.py`.
- Copied: 2026-11-12, from the design-refresh mood board's copy of the profile assets.
- SHA-256 at copy time:
  `554af887eefcd900713b7c4a2cd628466fdb0e46d466ba9c853886f170982d80`

To refresh:

```sh
curl -fsSL https://raw.githubusercontent.com/THEtheChad/THEtheChad/main/assets/hero.svg \
  -o src/components/SkylineHero/hero.svg
```

Then update the date and hash above, and re-check the alt text in
`SkylineHero.tsx` against the profile README's `<img alt>`.

Why an `<img>` and not inline markup: the file carries its own `<style>`
(including the generator's `prefers-reduced-motion` rule) and global ids
(`frame`, `sky`, `glowRed`, `drone`, …). As an image it stays a sealed
document: no id or class collisions with the page, no edits to the vendored
bytes, and a separately cached, hashed asset instead of ~50 KB in every HTML
response.
